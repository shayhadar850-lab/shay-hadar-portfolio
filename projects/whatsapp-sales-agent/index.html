איך המערכת מחוברת

המחשה טכנית המבוססת על מבנה המערכת.

WhatsApp Sales Agent+
  1. WhatsApp Webקליטת הודעה וסינון אירועי מערכת והודעות מחוץ לתחום.
  2. Message Handlerנרמול ההודעה וחילוץ פרטי השיחה.
  3. Conversationהחלת כללים, ניהול הקשר וזיהוי שפה וכוונה.
  4. Notion ↔ Gemmaקטלוג ו־CRM מספקים הקשר, ומודל השפה מנסח מענה.
  5. Reply / CRMהחזרת תשובה דרך WhatsApp ותיעוד האינטראקציה.

הבעיה והמטרה

מענה לשאלות על מוצרים דורש שילוב בין היסטוריית הפנייה, המלאי שהוגדר בקטלוג ושלב השיחה. המטרה הייתה לבנות תהליך שמנהל את שלושתם יחד ומעדכן את מערכת ה־CRM.

מה פותח

  • קליטת אירועי הודעה עם whatsapp-web.js, סינון הודעות וניהול שיחה לפי שולח. החיבור מבוסס על WhatsApp Web.
  • שליפת נתוני קטלוג מ־Notion, קריאה ועדכון של רשומות CRM וניהול הקשר שיחה, עגלה ושלבי מכירה.
  • קריאות ל־Gemma API עם היסטוריית שיחה והקשר קטלוגי, זיהוי עברית, אנגלית וערבית וכללים לבקרת קלט ומחירים.

האתגר הטכני

נדרש לשמור על רצף שיחה כשהודעות מגיעות בנפרד, ולהגן על התהליך מתקלות בשירותים חיצוניים. הקוד כולל מטמון לקטלוג, ניהול תוקף להקשר השיחה וניסיונות חוזרים מבוקרים לקריאות API.

בדיקות ואימות

הורצה חבילת הבדיקות של המאגר. 213 מתוך 215 בדיקות עברו בהרצת ברירת המחדל. שתי בדיקות של סינון הודעות ציפו שהודעות הדוגמה יעברו, בזמן שהגבלת השולחים חסמה אותן. חיבור מקצה לקצה לחשבון WhatsApp ול־Notion לא נבדק במסגרת הכנת תיק העבודות.
