מה אפשר לבנות יחד

משימה ממוקדת או מערכת שמחברת בין כמה צוותים וכלים.

אוטומציות ותהליכי עבודה

n8n · Make · Webhooks

  • תכנון תהליך מקצה לקצה, מבחירת הטריגר ועד למסירת התוצאה
  • שימוש ב־n8n וב־Make, תזמונים יומיים, בדיקות קלט וטיפול בחריגים

CRM ואינטגרציות נתונים

CRM · REST APIs · Notion

  • חיבור מערכות CRM לטפסים, לידים, קטלוגים ומערכות עסקיות
  • מיפוי שדות, סנכרון נתונים וניהול שלבי מעקב. Notion CRM מוצג בתיק העבודות

אוטומציות שיווק ופרסום

Social · Campaigns · Reporting

  • חיבור ערוצי סושיאל כגון פייסבוק ואינסטגרם לכלי פרסום, CRM ומודלים חיצוניים
  • הכנת טיוטות, תורי אישור, תזמון משימות ודוחות יומיים

חיבור מודלים וכלי AI

LLMs · MCP · Tool Calling

  • שילוב מודלי שפה חיצוניים דרך API לסיווג, סיכום ויצירת תוכן
  • פיתוח כלי MCP, חיבור סוכנים למערכות חיצוניות וניהול הקשר

עיצוב ופיתוח אתרים

Web Design · Astro · Responsive

  • עיצוב ובנייה של אתרים, דפי נחיתה וממשקי עבודה מותאמים לנייד
  • חיבור האתר לכלי מדידה, לטפסים ול־CRM לפי הצורך

תשתיות ותוספי דפדפן

Chrome MV3 · Cloudflare · Supabase

  • תוספי Chrome לקריאה והזנה של מידע עסקי דרך ממשקי דפדפן
  • Backend, אחסון נתונים, פריסה בענן, אימות והרשאות

תרחיש לדוגמה

מנתוני שיווק למשימות יומיות

כך אפשר לחבר מערכות שונות לתהליך עבודה אחד, מהאירוע הראשון ועד לתוצר שמגיע לצוות.

  1. אוספים מידע

    לידים מטופס אתר, הודעות או נתוני קמפיין נכנסים ממערכות שונות.

  2. מעבדים ומתזמנים

    תהליך ב־n8n או ב־Make בודק את המידע, מטפל בכפילויות ומופעל לפי אירוע או לוח זמנים.

  3. מחברים מודל AI

    המודל מסווג פניות, מסכם פעילות או מכין טיוטת תוכן לבדיקה.

  4. מעדכנים CRM

    רשומות מתעדכנות ומשימות מעקב נפתחות למי שאחראי עליהן.

  5. מוסרים תוצר

    הצוות מקבל משימות או סיכום יומי, ותוכן לפרסום עובר אישור במידת הצורך.

White-label

עבודה עם סוכנויות וצוותי תוכנה

אתם מנהלים את הקשר עם לקוח הקצה. אני מבצע את המשימה הטכנית לפי האפיון שלכם, עם בדיקות ותיעוד למסירה. אפשר לעבוד תחת המותג שלכם.

  1. מגדירים משימה ראשונה

    מסכימים על התוצאה, המערכות שצריך לחבר וקריטריוני הקבלה.

  2. בונים ובודקים מקצה לקצה

    אני מחבר את המערכות, בודק תרחישים אמיתיים ומתעד מה מפעיל את התהליך, מה הוא מחזיר ואיך מטפלים בחריגים.

  3. ממשיכים לפי הצורך

    משימה ראשונה יכולה להפוך לשיתוף פעולה קבוע בפרויקטים נוספים.

קצת עליי

אני שי הדר, סטודנט להנדסת תעשייה וניהול. אני בונה מערכות וכלי תוכנה שמחברים בין תהליכים עסקיים, נתונים ושירותים חיצוניים.

בפרויקטים שלי אני מוביל את האפיון, תכנון התהליך, האינטגרציה והבדיקות. אני משתמש בסוכני קוד מבוססי AI כחלק מהמימוש, ובודק בפועל את התוצאה.

איך לימודי ההנדסה מתחברים לעבודה שלי

  • תכנון וניתוח מערכות מידע — מיפוי צורכי משתמשים, זרימת נתונים וכללים עסקיים לפני שבונים.
  • ניהול טכנולוגיה וחדשנות — בחירת פתרון לפי הצורך העסקי ויכולת ההטמעה שלו.
  • חשבונאות והבנה פיננסית — חיבור בין עלויות, תמחור ובקרות בתהליכי מסחר.
  • מיקרו־כלכלה ומקרו־כלכלה — הבנת תמריצים, ביקוש ותנאי השוק שבהם עסק פועל.
